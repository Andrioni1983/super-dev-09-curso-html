Exercício 1 — Página HTML sobre Amsterdam Crie um arquivo chamado exercicio01.html e desenvolva uma página sobre Amsterdam, seguindo a estrutura abaixo. Estrutura da Página Título da aba (title) Amsterdam Pontos Turísticos Título principal da página Amsterdam Subtítulo Pontos Turísticos Pontos turísticos Crie 3 subsubtítulos, sendo um para cada ponto turístico. Para cada ponto turístico, inclua: 1 imagem 2 parágrafos descrevendo o local 1 link para mais informações sobre o ponto turístico Seção: Gastronomia Crie 4 subsubtítulos, sendo um para cada local gastronômico. Para cada local, inclua: 1 imagem 2 parágrafos 1 link para o local Avaliação do local Link de telefone do local Seção: Cultura Crie 2 subsubtítulos, sendo um para cada elemento cultural. Para cada um, inclua: 3 imagens 1 parágrafo 1 link relacionado ao tema
