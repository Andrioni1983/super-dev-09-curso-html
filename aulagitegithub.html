comandos GIT

GIT init-Inicializa um diretório
GIT clone-(link-repositório)- Faz o download de um repositório que esta no GitHub para sua máquina
GIT add - (nome do arquivo) - adicionar o arquivo para depois poder fazer um gitcommit(salva as alterações localmente) gitpusch(sobe a alteração para repositório)
Git status- verifica quais arquivos foram modificados, apagados e que estão no staging(antes da publicação para o repositório)
Git commit --message "mensagem das modificações", fecha um pacote com os arquivos criados, modificados, apagados que estão no staging
Git remote add origin (link do repositório link do GitHub) - local para onde seus commits (alterações) serão enviados
Git remote remove origin (link do repositório) - remove o link do repositório
Git remote get-url origin (exibir a URL (endereço) do repositório remoto que está configurado com o nome "origin" no seu projeto Gitlocal)
Git pull origin main(atualizar seu repositório local com as últimas alterações da branch main(ramificação principal do GitHub) no repositório remoto "origin" (computador do DEV)
Git push origin main - Enviar os commits (alterações) locais para o GitHub
Git log (verificar os commits locais e remotos)
Git branch -m main (alterar o nome da branch para main)
Git fetch atualiza o seu repositório local com os do GitHub remoto)
